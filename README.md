# EXP.NO.2-IMPLEMENTATION-OF-DIGITAL-MODULATION-TECHNIQUES

2.Implementation of Digital Modulation Techniques

    i) Amplitude Shift Keying (ASK)
    
    ii) Frequency Shift Keying (FSK)
    
    iii) Phase Shift Keying (PSK)

## AIM:

 To Study and Realize ASK,FSK and PSK Modulation and Demodulation using the Digital Modulation Trainer Kit. 
 
## APPARATUS REQUIRED:

Trainer Kit, DSO(10MHz) , Patch Cords and Power Supply (0-30V).

## PROCEDURE:

Switch ON the trainer kit and set the DC power supply to the required voltage. Use a function generator to produce a 1 kHz sine wave as the carrier and a 100 Hz square wave as the digital input. Connect both signals to the modulation input of the trainer kit. 
# For ASK, 
the amplitude of the carrier changes according to the digital input—carrier is present for logic 1 and absent for logic 0. 
# For FSK, 
the output frequency shifts between two values (e.g., 1 kHz and 500 Hz) based on the input logic. 
# For PSK, 
the carrier phase changes (0° or 180°) with the binary data. Connect the output of each modulation section to the DSO using patch cords and observe the waveform changes. Use the DSO’s triggering to clearly view the modulation. After observing all waveforms, turn OFF the trainer kit, DSO, and power supply.
